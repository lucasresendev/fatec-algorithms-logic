## 🎯 Enunciado

Reunir todos os algoritmos e exercícios desenvolvidos ao longo do semestre em uma aplicação única e interativa via console, com navegação simples e modular.

---

## 💻 Código Fonte

A implementação está disponível diretamente em [`consolidated_menu.ts`](consolidated_menu.ts).

---

## 🖥️ Opções do Menu

| Opção | Exercício / Módulo | Foco Principal |
| :---: | :--- | :--- |
| `1` | **Média de Notas do Estudante** | Tipagem estática, operadores aritméticos, precedência. |
| `2` | **Valor Final do Carrinho de Compras** | Modelagem de dados com `interface`, iteração de vetores, acumuladores. |
| `3` | **Soma de Dois Números** | Ciclo de vida de variáveis em 3 fases (Declaração $\rightarrow$ Inicialização $\rightarrow$ Atribuição). |
| `4` | **Lógica Booleana & Operadores** | Tabelas-verdade, avaliação em curto-circuito (`&&`, `\|\|`, `!`). |
| `5` | **Fluxo Decisório de Aprovação de Notas** | Fluxogramas ISO/ANSI, condicionais compostas, teste de mesa na RAM. |
| `6` | **Relatório de Notas Aninhadas** | Interfaces aninhadas, repetições bidimensionais, formatação com `.toFixed(2)` *(Meu estudo prévio)*. |
| `7` | **Tabuada com for** | Repetição contada `for`, comparando cálculo direto e meu uso de variável intermediária. |
| `8` | **Cálculo de Fatorial** | Acumulador multiplicativo, comparando método do professor com meus dois modelos desenvolvidos em aula. |
| `0` | **Sair** | Encerramento do programa. |

---

## 🚀 Como Executar

```bash
# Executar menu interativo a partir da raiz
npm start

# Ou diretamente via tsx
npx tsx src/00-consolidated-menu/consolidated_menu.ts
```
