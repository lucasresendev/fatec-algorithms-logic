## 🎯 Problem Statement

Unite all algorithms and coursework exercises developed across the semester into a single interactive console program.

---

## 💻 Source Code

The implementation is available directly in [`consolidated_menu.ts`](consolidated_menu.ts).

---

## 🖥️ Menu Options

| Option | Exercise / Module | Core Focus |
| :---: | :--- | :--- |
| `1` | **Student Grade Average** | Static typing, arithmetic operators, precedence. |
| `2` | **Shopping Cart Final Value** | `interface` data modeling, array traversal, accumulators. |
| `3` | **Sum of Two Numbers** | Fatec 3-phase variable lifecycle (Declaration $\rightarrow$ Initialization $\rightarrow$ Assignment). |
| `4` | **Boolean Logic & Operators** | Truth tables, short-circuit evaluation (`&&`, `\|\|`, `!`). |
| `5` | **Grade Approval Flow** | ISO/ANSI flowcharts, compound conditionals, RAM desk checking. |
| `6` | **Nested Grades Report** | Nested interfaces, multi-dimensional loops, `.toFixed(2)` precision *(My prior self-study)*. |
| `7` | **Multiplication Table** | Counted `for` loop, comparing direct calculation with my intermediate variable approach. |
| `8` | **Factorial Calculator** | Multiplicative accumulator, comparing professor's method with my two class approaches. |
| `0` | **Exit** | Graceful program termination. |
